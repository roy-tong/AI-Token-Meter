关联需求：`REQ-20260906-004`。用户明确要求发布，让已有机器可在应用内更新。

## 发布决定与顺序

目标0.3.0/build 11，不能继续只发Preview，否则现有macOS稳定appcast无法发现。沿用现有双平台发布流程，不更换验证公钥，不导出或记录私钥。

1. 同步根VERSION、两个plist、Windows npm/Cargo/Tauri以及README/CHANGELOG/Release Notes。
2. 运行完整验证，干净main打包签名macOS ZIP，创建同版本tag和草稿Release。
3. 标签上的macOS与Windows CI都通过后，由workflow公开双平台资产。
4. 最后推进稳定appcast与固定Windows Preview feed；下载线上资产核对SHA-256及两种签名，验证更新清单中版本和链接。
5. 完成后补发布节点、线上校验和、日志及需求状态。真实桌面项目与间歇性测试问题继续保持各自状态。

## 当前状态
