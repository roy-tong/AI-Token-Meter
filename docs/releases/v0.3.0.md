# AI Token Meter 0.3.0

双平台紧凑浮动条更新（macOS build 11）。macOS和Windows使用同一版本，保留账户配置、显示器位置、字体与更新签名公钥。

## 主要变化

- 默认Compact：78×286；可切换Comfortable：108×356。保留深海背景、连续肩部、三品牌颜色和Logo-only。
- Settings → Appearance支持服务显示/隐藏、排序，以及可选5秒/15秒闲置折叠；默认不折叠。至少保留一个服务，隐藏不停止采集。
- 右键浮动条可刷新、隐藏一小时、打开设置或退出。操作菜单时暂停详情自动隐藏。
- 外环继续表示额度，独立内环提示刷新或需登录/设置；详情显示缓存新鲜度，不用刷新状态改写额度。
- 按服务保存刷新退避，尊重Retry-After；取消不增加惩罚，重启和时钟回拨不绕过限流。
- 修正密度切换的位置中心、损坏新偏好不重置旧配置，以及重启后需登录状态的恢复。

## 如何更新

在 Settings → About 点击 **Check for Updates**，看到 **0.3.0** 后点击 **Update Now**。

- macOS 0.2.x和0.3.0-preview.x从现有稳定appcast发现本版（build 11）。
- Windows Preview从固定Preview feed发现本版；本版安装后使用稳定更新源。
- 更新会核对Sparkle EdDSA或Tauri minisign签名。无需重新安装CLI，设置和凭据存储位置不变。
- 0.1.2没有更新器，需要从[GitHub Release](https://github.com/sljzdotcom/AI-Token-Meter/releases/tag/v0.3.0)手动下载一次。

## 安装包与安全边界

- Apple Silicon macOS 14+：`AI-Token-Meter-0.3.0-macOS-arm64.zip`。
- Windows 11 x64：`AI-Token-Meter-0.3.0-windows-x64-setup.exe`。
- 两包均附SHA-256。macOS仍为ad-hoc signed、not notarized；首次安装可能需Finder右键“打开”。Windows没有Authenticode，SmartScreen可能提示unknown publisher；这不同于已经启用的内容更新签名。
- Widget证书与安装继续延期。Windows真实多DPI、多屏、读屏、官网登录和原位升级验收尚未全部完成；自动化通过不能替代真实交互。
- 已知间歇性CLI/PTY测试时序问题仍在需求列表追踪，未通过删断言或跳过测试掩盖。
